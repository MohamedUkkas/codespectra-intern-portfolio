# Mohamed Ukkas — Personal Portfolio

A responsive static portfolio website presenting Mohamed Ukkas's introduction, skills, selected work, and contact links.

## Sections

- Hero introduction with navigation
- About section with profile summary
- Skills display for HTML, CSS, Bootstrap, JavaScript, and C
- Portfolio section featuring a digital marketing website project
- Contact section with email, LinkedIn, and GitHub links

## Tech stack

- HTML5
- CSS3 with responsive media queries and animated skill bars
- JavaScript
- jQuery
- Font Awesome icons
- Google Fonts (Poppins)

## Project structure

```text
.
├── index.html       # Portfolio page and section markup
├── style.css        # Layout, theme, animations, and responsive styles
├── app.js           # Page behavior
└── Our work.png     # Portfolio project preview image
```

## Run locally

No build step is required. Clone the repository and open `index.html` in a browser:

```bash
git clone https://github.com/MohamedUkkas/codespectra-intern-portfolio.git
cd codespectra-intern-portfolio
python3 -m http.server 8000
```

Visit <http://localhost:8000>.

The page loads Font Awesome, jQuery, and Google Fonts from external CDNs, so an internet connection is recommended for the complete presentation.
