# Mohamed Ukkas — Personal Portfolio

A responsive static portfolio website presenting my introduction, early frontend work, skills, and contact links.

## What it demonstrates

- Responsive HTML/CSS layout
- JavaScript page behavior
- Portfolio and contact sections
- External library integration through CDN dependencies

## Technology

- HTML5
- CSS3 with responsive media queries
- JavaScript
- jQuery
- Font Awesome
- Google Fonts

## Project structure

```text
.
├── index.html       # Portfolio page and section markup
├── style.css        # Layout, theme, animations, and responsive styles
├── app.js           # Page behavior
└── Our work.png     # Portfolio preview image
```

## Run locally

No build step is required:

```bash
git clone https://github.com/MohamedUkkas/codespectra-intern-portfolio.git
cd codespectra-intern-portfolio
python3 -m http.server 8000
```

Visit <http://localhost:8000>.

The page loads Font Awesome, jQuery, and Google Fonts from external CDNs, so an internet connection is recommended for the complete presentation.

## Testing

There is currently no automated test suite. Manually verify navigation, responsive layouts, contact links, image loading, and external CDN behavior at common desktop and mobile viewport sizes.

## Scope and limitations

This is an early static portfolio project rather than a full-stack application. It has no backend, database, authentication, deployment pipeline, or automated accessibility test suite.
